# MarioCursach

2D-платформер в стиле Mario, написанный на Windows Forms с отрисовкой через GDI+ — без использования игровых движков.

## О проекте

MarioCursach — это классический 2D-платформер, реализованный «с нуля» на C# и Windows Forms. Вся графика отрисовывается средствами GDI+, а игровая логика, физика и обработка столкновений написаны вручную, без сторонних игровых движков. Уровень строится из тайловой карты, персонаж подчиняется гравитации и может прыгать, а камера плавно следует за игроком по мере его перемещения. Проект демонстрирует, как можно построить полноценную игровую механику, опираясь только на стандартные возможности .NET.

## Стек

- **C#** — основной язык разработки
- **.NET 8** (`net8.0-windows`) — целевая платформа
- **Windows Forms (WinForms)** — окно приложения и игровой цикл
- **GDI+** — отрисовка тайлов, персонажа и сцены

## Возможности

- Уровень на основе тайловой карты (tile-map)
- Физика гравитации и прыжков
- Покоординатная (per-axis) обработка столкновений AABB
- Камера, следующая за игроком (camera follow)

| Клавиша | Действие        |
|---------|-----------------|
| **A**   | Движение влево   |
| **D**   | Движение вправо  |
| **Space** | Прыжок         |

## Запуск

**Через Visual Studio:**

1. Откройте файл решения `.sln` в Visual Studio.
2. Соберите проект (`Ctrl + Shift + B`).
3. Запустите игру (`F5` или `Ctrl + F5`).

**Через командную строку:**

```bash
dotnet run
```
